# 工作流实操指南：如何实现高质量的上下文持续对齐

本指南为 Agent 在执行 **Context-of-User Skill** 时的官方执行指南。用于指导你在回顾对话、提炼共识、合并入库、冲突规避的全程实现无缝、无损的可复用开发。

---

## 预备阶段：触痛判定与非日志化拦截 (Trigger Assessment)
1. **拦截形式主义打卡**: context.md 是项目的“长期业务定义契约与共识底账”，**不要把它当作流水账、签到开发日志、或敏捷迭代轨迹进行记录**。
2. **触痛判定条件**: 只有在对话中讨论并敲定了**全新的软件级实体定义（Glossary）、修改或新增全局排外性非目标 (Non-Goals) 边界、或发生了重大的底层核心架构与决策变化**时，本更新流程才允许触发。
3. **无痛跳过**: 如果本此对话或需求属于已有名词框架、已知目标内的常规迭代，**不要修改、不要更新 context.md**，以保持它的绝对纯净和高信噪比。

## 阶段 1：对话痕迹深度审计 (Dialogue Audit)
1. **收集决策证据**:
   - 绝不可凭空想象来更新上下文。你必须逐行分析当前的对话，甚至包括上一次的历史对话切片，找出所有在以下层面产生变化的信息：
     - **术语发现**: 用户有没有开始使用一个新英文/中文代号指代某部分代码？
     - **目标变更**: 上一次定下的功能要点，是否在这次会话中被明确更改或补充？
     - **排除线索**: 用户有没有说“这太复杂了，先不要管这个”或“以后再说”？
2. **提取实体关系**:
   - 如果用户提到“A 应该通过 B 接口发往 C，但暂不需要 D 的确认”，这涉及 3 个 in-scope 项，1 个 glossary，和 1 个 out-of-scope（D 的确认）。

## 阶段 2：已有 context.md 冲突审查与合并
1. **读入现有 context.md**:
   - 若不存在，按 [context-template.md](context-template.md) 进行冷启动。
   - 若存在，先将其完全读入上下文，并将其中的 Glossary、Milestones、Consensus 与在 Stage 1 提取的当前对话进行交叉比对。
2. **规避覆盖与破坏 (No Overwrite)**:
   - ❌ **错误范式**: “由于有新共识，我将二、关键专有名词词汇表重构并清除了之前未提及的 3 处名词解释。”
   -  **正确范式**: “将新增名词安全地追加至‘关键专有名词词汇表’，并对以前定义但发生细维微调的名词，做精确的位置局部编辑 (Using Replace Substring)。”
3. **维护变更日志 (滚动追加)**:
   - 找到 `## 五、 上下文维护与变更日志` 部分。
   - 在其最顶端追加本次变更的具体日期（格式 `[YYYY-MM-DD]`）、更动提炼以及你的 Agent 代号署名。例如：
     ```markdown
     - **[2026-06-03]**: 增补了分发网关与 A-B 分流流程名词定义；新增支付暂不接入作为非目标排除范围。(By Agent - Context-of-User)
     ```

## 阶段 3：极致简短访谈与验证
- **沟通原则**: 用简练的语言将你更新或创建 [context.md](context.md) 的最终姿态高亮呈现给用户，询问是否有理解发生偏差。
- **优秀反馈模板**:
  ```markdown
  我已经为您和后续 Agent 增量更新/初始化了根目录的 [context.md](context.md) 档案。

  ### 本次对齐共识摘要
  1. **新增专有名词**：`XXX` (此处附简短解释)
  2. **新增项目核心目标/里程碑**：`YYY`
  3. **新增已被排除的 Non-Goals**：`ZZZ (暂不开发)`
  4. **新增的共识与技术选型决策**：`由于...采用...方案`

  您也可以打开根目录中的 [context.md](context.md) 了解全貌。请问您对本次对齐的业务事实、名词规范或排除范围有无修改建议？
  ```

## 阶段 4：对照 what-is-good-context.md 的质量校验 (Self-Check)
- 出库之前自检：
  - [ ] 是否在 [context.md](context.md) 中添加了具体的，属于用户当前的业务属性？
  - [ ] 是否存在 placeholder（模板占位符）未被清除干净？
  - [ ] 底部日志更新了没有？
  - [ ] 是否严格没有删除任何已有的、仍然在有效范围内的历史概念？
