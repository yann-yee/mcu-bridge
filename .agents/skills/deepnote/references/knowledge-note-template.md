## Distillation Rules

- 不是逐段复述 Source；
- 一个 Note 围绕一个可复用概念；
- 多个 Source 支持同一 Claim 时合并为知识，不重复摘要；
- 争议内容保留冲突；
- `verified` 只用于已有足够证据的知识；
- Source 更新后允许增量修订，不创建互相冲突的新事实。
