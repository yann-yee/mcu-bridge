# 笔记结构计划

在撰写之前，请你根据已经收集到的证据清单，勾画出笔记的骨架。这个计划是施工图纸，决定了最终笔记的质量。

---

## 笔记标题
- 格式：`[论文标题] 阅读笔记`

## 1. 一句话总结
- **内容**: 以不超过30字概括问题和核心方法。必须包含方法名。
- **将用证据**: 问题定义 (证据项1) + 方法定位 (证据项2)

## 2. 动机与问题定位
- **计划内容**: 为什么现有方法不行？本文要填的缺口具体是什么？
- **将用证据**: 证据清单中的问题定义、introduction 中提及的限制。
- **溯源计划**: 引用 Introduction 或 Related Work 中的具体句子位置。
- **缺口预判**: 若原文动机描述空洞，计划中注：“此处原文动机不够充分，笔记将指出这一点”。

## 3. 方法核心
- **计划展开的子章节**:
  - 例如：3.1 整体架构、3.2 提出的 X 模块、3.3 训练策略
- **每个子章节预定的证据**:
  - 引用的公式编号及计划使用 `「原文：...」` 的位置
  - 计划引用的图表（图X）及其说明文字
- **技术深度目标**: 明确哪个子章节将写得更详实（达到“技术细节丰满”标准）。

## 4. 实验关键发现
- **将要展示的数据**:
  - 主实验数字 (证据项6) 及其溯源 `(§4.2 表2)`
  - 关键对比 (证据项6) 及其对比条件说明
- **将要引用的图表**: 图/表编号列表
- **消融实验要点**: 用1句总结，引用证据项7。
- **如果缺乏公平对比信息**: 预先计划在此处执行豁免声明。

## 5. 局限性与边界
- **计划包含的内容**:
  - 作者承认的局限 (证据项10) —— 直接引用原文或精确复述
  - 作为阅读者的你分析出的潜在局限 —— 必须标记 `[个人分析]`
- **缺口处理**: 若论文无明确 Limitations，计划此处写 `ⓘ 论文未讨论局限性，以下为个人分析`。

## 6. 我的见解
- **计划写什么**: 基于证据的讨论，而非空泛感想。比如：该方法为何在此任务有效？该设计是否可迁移？
- **约束**: 若没有充分证据支持，降低语气为推测，并标记为 `[推测]`。

---

**重要**: 这份计划不是在笔记里贴出来的提纲，而是指导你写作的内部指令。在阶段3，你必须严格将证据填入对应计划位置，不得写计划中没锚定证据的内容（发现新洞察除外，但需回溯证据）。
