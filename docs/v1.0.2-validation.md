- Checked JSON integer conversion and supplied optional-type validation prevent invalid requests from reaching target operations. Dynamic schema describes command/state/parameter and event metadata.
- Sampler/monitor wait and lock-acquisition paths respond to stop signals and join. In-progress synchronous driver calls must return before cleanup can finish.
- Default probe-rs tests no longer connect real probes. Breakpoint allocation failure preserves counters and prior mappings. Unsupported Semihosting capture is not advertised as usable.

Separate mock tests exercise sampler/monitor lock contention, long waits, interruptible recovery, cleanup after a controlled active read, startup flags/config precedence, physical-halt initialization ordering, and flash/doctor success/failure paths.

### Regression sensitivity

An independent validator copied only the build/source/test inputs into a dedicated OS-temp directory and deliberately replaced finite `recv_timeout` scheduling with blocking `recv`. The targeted idle-input test compiled and failed after approximately five seconds waiting for JSON output. The production JSON source hash remained unchanged. Child processes were reaped and the scratch directory was removed after verifying its exact OS-temp location.

This demonstrates that the test rejects restored input-dependent scheduling. It is not a run of the released v1.0.1 binary and does not establish hardware behavior.

### Corrections during validation

- A broken-pipe fixture initially allowed the Rust test harness to write completion output to the deliberately closed pipe. The child now asserts the production error and detach before exiting, preserving the actual cleanup claim.
- A sampler test incorrectly required exactly one sample while an independently scheduled sampler continued running. The mock now halts at its first status poll, retains the strict one-sample assertion, and finishes deterministically; five focused reruns plus the final full suite passed.
- Formatting and three Clippy findings were fixed without lint suppression. Final checks above apply after corrections.
